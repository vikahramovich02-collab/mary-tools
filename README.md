# mary-tools

Служебные страницы команды Mary. Лежат по неугадываемым адресам,
закрыты от поисковиков через `robots.txt` и `noindex`.

Репозиторий публичный по необходимости: GitHub Pages на бесплатном плане
не отдаёт страницы из приватных репозиториев. Поэтому здесь не должно быть
ничего чувствительного — ни ключей, ни токенов, ни данных клиентов.
Адреса страниц знают только свои.

Что внутри: панель воронок и сборщик ссылок с UTM-метками.
